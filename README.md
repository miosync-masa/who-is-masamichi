# who-is-masamichi

> A version-controlled, multi-perspective model of one continuously changing human.

This repository does **not** define the authoritative truth of who Masamichi Iizumi is.

It preserves how different observers currently understand him, why those interpretations changed, where they disagree, and how Masamichi himself responds to those interpretations.

## Start here

A new collaborator or conversation should read, in order:

1. [CURRENT_MODEL.md](CURRENT_MODEL.md)
2. [Concept separations](epistemology/concept-separations.md)
3. [Humor and pragmatics](epistemology/humor-and-pragmatics.md)
4. The relevant observer file under [lenses/](lenses/)

Project status does not belong here. Use Notion for current research and production state, and each project repository for implementation truth.

## Core principles

- The repository models understanding, not the person.
- `main` is the current integrated view, not final truth.
- A commit records a revision of understanding.
- A diff records what changed in that understanding.
- A branch or pull request preserves an observer's distinct lens.
- A merge conflict exposes meaningful disagreement (`mΔ`).
- Masamichi's review is high-value evidence, not an automatic erasure of external observation.
- Temporary preferences must not become permanent personality claims.
- Raw conversation logs are not stored by default; representative evidence anchors are preferred.
- Contradictions may remain unresolved until a context-dependent model explains them.

## Structure

- `CURRENT_MODEL.md` — current integrated model
- `epistemology/` — interpretation and update rules
- `lenses/` — observer-specific relational views
- `anchors/` — representative evidence that changed the model
- `conflicts/` — unresolved or productive disagreements
- `.github/` — contribution and review templates

The repository itself is expected to evolve through pull requests.
