# Evidence anchors

Anchors are representative events that materially changed an observer's model. They are not a conversation archive.

## Include

- date or approximate period
- observers involved
- concise paraphrase of the event
- previous interpretation
- revised interpretation
- scope and confidence
- link to a public artifact when safe and useful

## Exclude by default

- full private transcripts
- credentials, addresses, or unnecessary personal data
- emotionally vivid details that do not support the claimed revision
- evidence selected only to make an observer look correct

## Template

```yaml
date: YYYY-MM-DD
observers: []
scope:
confidence:
user_review: pending
supersedes:
```
