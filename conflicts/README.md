# Conflicts and mΔ

A conflict is not automatically an error. It may reveal a missing variable.

Example:

- “He structures difficult problems internally before sharing them.”
- “He shares unfinished thoughts freely with trusted collaborators.”

Possible synthesis:

> The level of internal preprocessing varies with relationship, task type, urgency, and whether the conversation is exploratory or operational.

## Conflict record

Each conflict should include:

- competing claims
- observers and scopes
- evidence anchors
- candidate hidden variables
- current synthesis, if any
- reason the conflict remains open
- Masamichi's review

Do not resolve a conflict merely to make `main` look consistent. Resolve it when the new model explains more observations with fewer arbitrary exceptions.
